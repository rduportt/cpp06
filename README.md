# CPP Module 06

> C++ casts.

## What's inside

- static_cast, reinterpret_cast, dynamic_cast
- Scalar type conversion
- Serialization
- Identifying the real type of an object

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
